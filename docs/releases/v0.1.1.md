# Warden MCP v0.1.1

Status: draft release notes

## Highlights

- npm installs now deliver a fully working native `warden-mcp` binary
- Go installs remain supported via `go install`
- release packaging now includes per-platform binaries plus SHA-256 checksums
- repository licensing is now explicit with the MIT license

## User-facing changes

### Native install via Go

```sh
go install github.com/Blu3Ph4ntom/warden-mcp/cmd/warden-mcp@latest
```

### Native install via npm

```sh
npm install -g warden-mcp
```

The npm package now downloads the matching native binary for the package version from GitHub Releases during installation.

## Operator notes

- publish the GitHub release assets before publishing `warden-mcp@0.1.1` to npm
- if npm install fails in locked-down networks, users can still fall back to the Go install path
- `npm rebuild warden-mcp` retries the native binary download for an existing install
