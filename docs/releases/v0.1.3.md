# Warden MCP v0.1.3

Status: patch release notes

## Highlights

- fixes Codex-style MCP startup by supporting line-delimited JSON transport in addition to framed stdio transport
- broadens MCP startup discovery compatibility for newer client flows
- includes the `get_agent_guide` MCP tool for agent bootstrap guidance
- keeps the `warden-mcp` no-arg default-to-serve behavior introduced in `0.1.2`

## User-facing fix

Some MCP clients start local servers using newline-delimited JSON-RPC messages during startup and capability discovery.

As of `v0.1.3`, `warden-mcp` supports both:

- framed stdio MCP messages using `Content-Length`
- line-delimited JSON startup flows used by compatible clients

This fixes clients that previously showed the server as enabled but failed to discover any tools.

## Install

### Native install via Go

```sh
go install github.com/Blu3Ph4ntom/warden-mcp/cmd/warden-mcp@latest
```

### Native install via npm

```sh
npm install -g warden-mcp
```
