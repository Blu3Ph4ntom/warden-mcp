# Warden MCP v0.1.6

Status: patch release notes

## Highlights

- improves marketplace and coding-agent onboarding with a faster README quickstart
- surfaces `get_agent_guide` as the recommended first-call workflow for agent clients
- tightens package discovery metadata for MCP and coding-agent ecosystems
- expands parser, render, evaluator, and packaging validation coverage before release

## User-facing changes

As of `v0.1.6`, coding-agent users get a cleaner add/setup path:

- install with `npm install -g warden-mcp` or `go install github.com/Blu3Ph4ntom/warden-mcp/cmd/warden-mcp@latest`
- verify the local install with `warden-mcp health` or `npx warden-mcp health`
- connect `warden-mcp` as a local MCP server
- call `get_agent_guide`, then `health_check`, then `get_status`

This patch does not change the core install model from `0.1.5`; it makes the package easier to discover, adopt, and validate for agent-focused workflows.
