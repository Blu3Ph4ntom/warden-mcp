# Warden MCP v0.1.2

Status: patch release notes

## Highlights

- fixes MCP client compatibility when launching `warden-mcp` with no CLI args
- keeps explicit CLI subcommands like `health`, `status`, and `serve` unchanged
- preserves the native npm install flow introduced in `0.1.1`

## User-facing fix

Many MCP clients launch a local server using only the configured command name.

As of `v0.1.2`, running `warden-mcp` with no arguments now defaults to MCP stdio server mode, which is equivalent to:

```sh
warden-mcp serve
```

This means a config like the following now works without extra args:

```json
{ "command": "warden-mcp", "args": [] }
```

## Install

### Native install via Go

```sh
go install github.com/Blu3Ph4ntom/warden-mcp/cmd/warden-mcp@latest
```

### Native install via npm

```sh
npm install -g warden-mcp
```
